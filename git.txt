useRef и useMemo

1) useRef - Сохранение данных между рендерами, так чтобы изменения не вызывали перерисовку
2) useMemo - Запомнить результат тяжелых вычислений между рендерами

useRef 
Возвращает изменяемый объект-контейнер, сохраняющий свое значение между рендерами компонента.
.current - свойство объекта (изменяемое), которое отвечает за текущее состояние объекта
{current: 'начальное значение'}
нужен, когда делаем небольшие изменения, которые неоправданно делать через useState и useEffect

ref.current = 'новое значение'
	1. Для доступа к DOM-элементам
	2. Для хранения "тихого" состояния (предыдущие значения пропсов, значения счетчиков) - все то, что не участвует в отрисовке интерфейса


useMemo
Хук для кэширования (мемоизации) результатов вычислений. Нужен для оптимизации производительности.
useMemo(function, [зависимости]);
	1. При первом рендере выполняется функция и сохраняется результат
	2. При повторном рендере, еслизависимости не изменились - он берет готовый результат, заново перерасчет происходить не будет.
